# 私有离线授权

本项目的授权模块用于限制可添加的**订阅链接数量**。未授权版本默认最多保存 1 条订阅链接；订阅链接解析出的节点数及手动节点数不受限制。

授权完全离线，不调用第三方授权服务器，也不依赖第三方加密库。实现仅使用 Go 标准库中的 Ed25519、SHA-256、JSON 和安全随机数。

## 安全模型

- 签发机保存 Ed25519 私钥，用于生成授权码。
- 发布的 `sbm` 二进制只嵌入公钥，只能验证，不能签发。
- 每次安装首次启动时生成随机设备标识，保存在数据目录的 `device.id`（权限 `0600`），界面展示由其派生的六位设备码。
- 授权码绑定设备码，包含授权编号、订阅链接上限和可选到期时间，并由私钥签名。
- 本地只保存已签名的授权码，程序每次启动都会重新校验签名、设备和有效期。
- 私钥不得加入 Git、Docker 镜像、服务器或交付包。本仓库已忽略常见的授权密钥文件名。

## 1. 生成你自己的密钥

在一台可信、最好不对外提供服务的签发机上执行：

```bash
go run ./cmd/license-tool keygen \
  -private license-private.key \
  -public license-public.key
```

两个文件都使用 Base64 文本格式。私钥文件以 `0600` 创建；如目标文件已存在，工具会拒绝覆盖。

## 2. 把公钥嵌入发布版本

```bash
LICENSE_PUBLIC_KEY="$(tr -d '\n' < license-public.key)" \
FREE_SUBSCRIPTION_LIMIT=1 \
./build.sh current
```

Docker 构建：

```bash
docker build \
  --build-arg LICENSE_PUBLIC_KEY="$(tr -d '\n' < license-public.key)" \
  --build-arg FREE_SUBSCRIPTION_LIMIT=1 \
  -t sbm-private .
```

只嵌入公钥。没有嵌入公钥的开发构建仍可按免费额度运行，但会拒绝激活任何授权码。

## 3. 给设备签发授权

客户在“设置 → 软件授权”复制六位设备码，例如 `409502`。在签发机执行：

```bash
go run ./cmd/license-tool issue \
  -private license-private.key \
  -device 409502 \
  -subscriptions 20 \
  -expires 2027-12-31 \
  -id customer-001
```

命令输出以 `CMS1.` 开头的授权码。将它交给客户，在软件授权页面激活即可。省略 `-expires` 表示永久授权。

## 行为说明

- 达到上限后新增订阅接口返回 HTTP 403，已有订阅可以刷新和编辑。
- 删除一条订阅后可重新添加，数量按当前保存的订阅链接计算。
- 导入的备份如果包含超过当前授权上限的订阅，会被拒绝且不会覆盖现有数据。
- 清除或授权过期后额度恢复为 1；已有的超额数据不会被删除，但不能继续新增，避免授权变化造成数据损失。
- 更换数据目录或删除 `device.id` 会产生新的设备码，原授权不再匹配。

## 边界

离线授权能可靠阻止普通用户误用或直接伪造授权码，但任何完全运行在客户机器上的程序都无法做到绝对不可破解。应配合闭源交付、去除调试信息、严格保管私钥和明确的商业协议使用。授权模块本身没有远程停用、联网追踪或收集设备硬件信息。
